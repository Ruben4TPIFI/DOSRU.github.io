Man-in-the-Middle Attack with Ettercap (ARP Spoofing)

Project Overview

This project demonstrates a Man-in-the-Middle (MITM) attack using Ettercap in a controlled laboratory environment to understand how attackers intercept network traffic.

Attack Scenario

  • Isolated network hosted in a Proxmox lab
  • ARP spoofing used to poison victim ARP cache
  • Attacker positioned between victim and gateway
  • Traffic intercepted and analyzed

Security Concepts Covered

  • Man-in-the-Middle (MITM) attacks
  • ARP cache poisoning
  • Layer 2 network vulnerabilities
  • Traffic interception and analysis

Tools & Environment

Ettercap, ARP Spoofing, MITM, Wireshark, Proxmox,
