Web Application Security Scanner

Objective

Develop a basic web security scanner capable of identifying common vulnerabilities in web applications.

Description

This project involved creating a web scanner that analyzes web pages for potential security weaknesses such as insecure HTTP headers, exposed inputs, and basic injection points. The scanner performs automated checks and reports findings in a structured format.

Key Findings / Learning Outcomes

  • Identified missing or insecure HTTP security headers
  • Analyzed input fields for potential injection risks
  • Improved understanding of common OWASP Top 10 vulnerabilities
  • Learned how automated scanners enumerate attack surfaces
